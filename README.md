# AliSnow

Нативное macOS-приложение с живым снегом поверх экрана на базе **Metal** и **SwiftUI**. Снег полностью просчитывается на GPU, реагирует на движение курсора и управляется из Menu Bar.

## Возможности

- **GPU-симуляция на Metal** — до 2 500 снежинок с параллаксом глубины, плавным покачиванием, ветром и мягким свечением.
- **Реакция на курсор** — курсор отталкивает снежинки и создаёт воздушный след при движении мыши (работает глобально поверх любых приложений без запроса лишних разрешений).
- **Прозрачный click-through оверлей** — не перехватывает клики, работает поверх всех экранов и рабочих пространств (Spaces).
- **Управление из Menu Bar** — иконка снежинки в верхней панели (без иконки в Dock):
  - включение/выключение снега;
  - включение/выключение реакции на курсор;
  - настройка интенсивности снегопада и силы ветра.
- **Без App Sandbox** — проект сразу подготовлен для дальнейшей интеграции с координатами иконок/папок Finder.

## Требования

- macOS 14.0+
- Xcode 16+ (протестировано на Xcode 27.2 / Apple Silicon)
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) *(опционально, если нужно перегенерировать `.xcodeproj` из `project.yml`)*

## Быстрый старт

### Через Xcode
1. Открой проект:
   ```bash
   open AliSnow.xcodeproj
   ```
2. Нажми **Cmd + R** — поверх экрана пойдёт снег, а в Menu Bar появится иконка снежинки.

### Через терминал (`xcodebuild`)
```bash
xcodebuild -project AliSnow.xcodeproj -scheme AliSnow -configuration Debug -derivedDataPath build/DerivedData build
open build/DerivedData/Build/Products/Debug/AliSnow.app
```

> **Примечание:** `SnowShaders.metal` копируется в ресурсы приложения и компилируется системным runtime-компилятором Metal при запуске (с автоматическим приоритетом `default.metallib`, если установлен `MetalToolchain`). Это позволяет собирать и запускать проект сразу без скачивания дополнительных компонентов Xcode.

## Структура проекта

```text
AliSnow/
├── AliSnowApp.swift        # Точка входа, MenuBarExtra и прозрачные NSWindow-оверлеи
├── SnowRenderer.swift      # MTKViewDelegate, Metal pipeline, трекинг курсора
├── SnowShaders.metal       # Compute-шейдер физики (updateSnow) + vertex/fragment рендер
└── Assets.xcassets         # Иконка и цвета приложения
AliSnow.xcodeproj/          # Xcode-проект (macOS, SwiftUI, App Sandbox отключён)
project.yml                 # Конфигурация XcodeGen
```

## Производительность

- **Буфер частиц:** `2 500 × 32 байта ≈ 78 КБ` + `48 байт` юниформов на кадр.
- **Рендер:** `1 compute dispatch` + `1 draw call` (`.point` примитивы), время шейдеров на Apple Silicon **< 0.3 мс/кадр**.
- **CPU:** ~1–3% на 60 FPS (вся физика и отрисовка выполняются на GPU).
- **Память:** ~50–90 МБ (основной объём — фреймбуфер полноэкранного прозрачного `MTKView`).
